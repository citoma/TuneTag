核心功能

把标签整理，变成一件轻松的事

从导入到导出，每一步都为「少操作、不出错」而设计。

⬇

拖拽即导入

支持拖入文件、批量文件或整个文件夹，自动递归读取并按格式过滤，列表即刻呈现。

✎

单文件精修

标题、艺术家、专辑、年份、曲目号、曲作者、词作者、流派、歌词与封面，逐项编辑、即时预览。

⚡

批量设值 + 清空

为多首曲目统一写入同一字段值，或一键清空指定字段，整张合集一次搞定。

🖼

封面与歌词

MP3 支持内嵌封面编辑，歌词可内嵌写入；常用值会以历史芯片形式一键回填。

🛡

安全导出

「保存」即导出到你选择的文件夹，默认不原地覆盖原始文件，整理过程零风险。

📊

状态可视化

未修改 / 已修改 / 已导出 / 保存失败一目了然，导入与导出数量实时统计。

工作方式

三步完成标签整理

无需学习成本，导入即可上手。

1

拖入文件

把音乐文件或文件夹拖进窗口，乐签自动识别并列出可编辑曲目。

2

编辑标签

单选精修或批量设值/清空，封面与歌词一并处理，历史值随取随用。

3

导出保存

选择目标文件夹导出，进度与成功/失败反馈清晰，原始文件保持不变。
